# MusicXCST Downloader

Private Windows desktop downloader app by **B1progame**.

MusicXCST Downloader is a standalone app built with Python, pywebview, yt-dlp, and FFmpeg. It is not the Minecraft mod and is not bundled into any Minecraft mod jar.


## Quick Build

```powershell
cd musicxcst_downloader
.\scripts\build_exe.ps1
```

Output:

```text
musicxcst_downloader\dist\MusicXCST Downloader\
```
