# Third-party notices

MusicXCST Downloader uses the following third-party tools and libraries:

- pywebview: desktop webview window and Python bridge.
- yt-dlp: metadata extraction and download support.
- FFmpeg and ffprobe: media merging, conversion, and probing. Users provide FFmpeg from PATH or a custom path.
- PyInstaller: Windows executable packaging.
- Inno Setup: optional Windows installer packaging.

This app does not bundle FFmpeg by default. If a future managed FFmpeg download is added, the download URL, SHA-256 checksum, license text, and storage location must be shown clearly to the user before download.
